# Simple Run

ただ走る白いマネキンを、ドラッグで左右に動かして箱と奈落を避けるスマホ向けブラウザゲーム。

## ローカル起動

Node.js 22以降。

```sh
npm ci
npm run dev
```

同じWi-Fiのスマホから、起動時に表示されるNetwork URLを開いてください。縦画面推奨。OSのファイアウォールがある場合はローカルネットワークからの接続を許可してください。

画面の再生ボタンで開始。画面のどこからでも左右にドラッグできます。説明文はゲーム内に表示しません。PCでもマウスドラッグで確認できます。

```sh
npm test
npm run build
npm run preview
```

`dist/` が静的公開物です。相対アセットパスなのでGitHub Pagesのサブディレクトリにも配置できます。ソースは [GitHub](https://github.com/GoukiKatagiri/Simple-Run) で管理しています。

## 設計と調整

詳細は [docs/DESIGN.md](docs/DESIGN.md)。`src/core.js` に速度、横移動、障害物生成と判定、`src/main.js` に描画・カメラ・入力・画面遷移、`src/runner.js` に人型モデルとアニメーション制御があります。`intervalAt()` が障害物の到達間隔、`speedAt()` / `distanceAt()` が加速を決めます。

Three.jsの[公式ドキュメント](https://threejs.org/docs/pages/WebGLRenderer)に沿ったWebGL描画です。runnerにはQuaterniusのCC0人型モデルと走行アニメーションを加工したローカルGLBを使用します。ゲーム実行時に外部サービスから取得することはありません。素材と加工内容は [docs/ASSETS.md](docs/ASSETS.md) に記載しています。依存ライブラリのライセンスは各パッケージに従います。このプロジェクト本体の公開ライセンスは未設定です。

## 動作について

スマホの縦画面でのプレイを想定しています。端末によって描画性能や音量は異なります。効果音はブラウザ内で合成します。BGMはありません。自己ベストはこのブラウザ内だけに保存します。

## 障害物配置

最高速度70へ120秒で加速。左右の切り返し・狭い通路・両側の中央通路・少量の休憩を混ぜます。`Course.append()` は1〜2個の障害物を持つ配置行を返し、`safeIntervals()` が組全体の通路、`groundSections()` が複数の奈落を差し引いた床区間を計算します。箱の奥行きは1.5、奈落は5.5が上限です。

## 演出とリズム

`src/sound.js` に回避・記録・失敗時の短い音、`src/runner.js` に残像を追加。400m以降に短い配置セット、900m以降に4配置の難所と直後の1.3〜1.6秒の到達間隔を追加します。難所は最低20秒空けて再登場します。自己ベスト地点は、床に細い線として表示します。
